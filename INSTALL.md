# INSTALL.md — инструкция для агента

Ты — Hermes-агент, и человек попросил поставить travel-скилл из этого репозитория. Делай по
шагам, каждый шаг — команда через `terminal` и проверка её вывода. Не выдумывай пути и версии:
всё нужное здесь. Ключей и оплаты не требуется.

## 0. Что получится

Роль «Штурман поездки» (`skills/travel/travel-role/SKILL.md`): по просьбе человека ищет перелёт
и дорогу до аэропорта, считает цену «до двери» в злотых и присылает 2–3 варианта со ссылками на
покупку. Источники без ключей: Kiwi (MCP), fare-finder Ryanair, Google Flights (fast-flights),
AZair, Flixbus, ленты распродаж (RSS и Telegram-превью). Ничего не покупает и не бронирует.

## 1. Установка (одна команда)

```sh
rm -rf /tmp/hermes-travel-skill && git clone https://github.com/ilya0013/hermes-travel-skill /tmp/hermes-travel-skill && bash /tmp/hermes-travel-skill/install.sh --check
```

`HERMES_HOME` у тебя — обычно `/opt/data` (образ Hostinger); другой — добавь `--home=<путь>`.
Скрипт ставит роль, venv источников (`travel/lib/venv`, через `uv`), каталоги
`travel/{reports,interest,watch}` и cron-обёртку `scripts/travel/interest_digest.sh`.
Повторный запуск безопасен: `profile.yaml` и журнал остаются.

**Успех — пять строк в выводе:** `роль установлена…`, `venv: fast-flights 3.1.0;flywizz 0.1.0;mcp 2.2.0;…`,
`report.py под питоном Hermes: ок`, `hermes skills list: travel-role виден`, `Kiwi отвечает: ок`. Нет строки про Kiwi — скажи
человеку, что сеть до `mcp.kiwi.com` не ответила, остальное стоит. Любая другая ошибка —
покажи человеку вывод как есть, не чини вслепую.

## 2. Три вопроса человеку (одним сообщением)

1. Годится ли Модлин (Ryanair, автобус ~1 ч из Варшавы) или только Шопен?
2. Сколько человек обычно летит?
3. Есть ли направление, которое интересно в ближайшие месяцы, и потолок цены — чтобы завести
   «интерес» (свод распродаж по понедельникам)? Можно «нет».

Ответы 1–2 — в `$HERMES_HOME/skills/travel/travel-role/profile.yaml`: `airports.WMI.ok`
(`true` / `false` / `ask`), `travelers.adults`. Файл читай и правь целиком, комментарии в нём —
подсказки. Город и аэропорты там уже варшавские; человек из другого города — спроси аэропорт,
цену дороги до него в злотых и впиши по образцу `WAW`.

Ответ 3 — если «да»: заведи интерес и cron по `references/watch.md` роли (файл
`travel/interest/<имя>.json`, `cronjob create` с `script: travel/interest_digest.sh`, `0 9 * * *`,
доставка туда, где человек пишет тебе). Если «нет» — ничего не заводи, cron без интересов не нужен.

## 3. Google Диск (по желанию)

`report.py` кладёт таблицу всех найденных строк в Google Doc через скилл `google-workspace`.
Нет токена Google — таблица остаётся файлом `travel/reports/<run>.md`, ответ человеку всё равно
приходит целиком. Настраивать Google не обязательно; захочет — `hermes auth` по документации Hermes.

## 4. Проверка живьём

Попроси человека прислать запрос в его стиле, например: «найди перелёт Варшава–Будапешт в
октябре на 2–3 ночи, лечу один, только рюкзак, Модлин годится, важнее цена». Роль включится
сама (по смыслу просьбы). Хороший ответ: ★ у самого дешёвого до двери, у каждого плеча аэропорт
словами и ссылка на покупку, строка «Источники: ✅ … ❌ …», последней — «Подробно → ссылка».

## 5. Если что-то не так

* `hermes skills list` не видит `travel-role` — агент запущен с другим `HERMES_HOME`; поставь
  с `--home=<его путь>`.
* Скрипт источника упал — роль сама переходит к следующему (`references/sources.md`), в ответе
  будет ❌ с причиной. Это норма, не ошибка установки.
* Обновить роль — та же команда из шага 1: файлы перезапишутся, профиль и журнал останутся.
