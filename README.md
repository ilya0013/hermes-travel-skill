# hermes-travel-skill

[![version](https://img.shields.io/github/v/tag/ilya0013/hermes-travel-skill?label=version)](https://github.com/ilya0013/hermes-travel-skill/tags)
[![license](https://img.shields.io/badge/license-MIT-green)](LICENSE)
![Hermes Agent](https://img.shields.io/badge/Hermes%20Agent-skill-blue)

**«Штурман поездки» для [Hermes Agent](https://hermes-agent.nousresearch.com)** — скилл, который превращает личного
агента в искателя дешёвых перелётов из Польши. По просьбе человека ищет перелёт и дорогу до аэропорта, считает цену
**до двери в злотых** и присылает 2–3 варианта со ссылками на покупку — по возможности у самой авиакомпании.

Не покупает и не бронирует. Платных API и ключей не нужно.

## Пример

> Найди перелёт Варшава–Барселона 27–30 ноября, лечу один, только рюкзак, только Шопен, важнее цена.

Ответ агента (до 20 строк): вердикт одной фразой, ★ — самый дешёвый до двери, 2–3 варианта; у каждого плеча дата,
аэропорт словами, перевозчик, цена и ссылка на покупку; риски (раздельные билеты, короткая стыковка, ночной прилёт);
строка «Источники: ✅ … ❌ …» и «Подробно → ссылка» на таблицу всех найденных цен.

## Возможности

- **Цена до двери** — билет плюс дорога дом ↔ аэропорт (ZTM до Шопена, автобус до Модлина по живой цене Flixbus),
  курс НБП для валютных тарифов.
- **Много источников сразу** — Ryanair (fare-finder), Google Flights (все перевозчики, в том числе Wizz и Turkish по
  цене перевозчика), Kiwi (связки, багаж, окно дат, «на выходные»), Skiplagged (все авиакомпании, календарь дешёвых
  дней), AZair (связки лоукостеров), ленты охотников за распродажами (польские и европейская Travel-Dealz).
- **Варианты собирает код, а не модель** — `report.py --auto` сам складывает поездки из найденных строк (одним
  билетом и парами плеч, через два аэропорта одного города) в окне дат запроса и ставит ★; на точных датах
  («с 27 по 30») предупреждает, если ★ короче окна. Числа в ответе — только из его вывода.
- **Ссылка у авиакомпании** (по желанию) — через бесплатный аккаунт [SlickTrip](https://slicktrip.com): для рейсов
  из Google и Kiwi агент находит продавца-перевозчика и даёт ссылку на оплату у него.
- **«Куда дешевле»** — все направления Ryanair из Шопена и Модлина одним вызовом; все авиакомпании — через Skiplagged
  (3 самых дешёвых города сразу с рейсами и аэропортами); связки — через Kiwi.
- **Поездом к соседям** — RegioJet (Прага, Вена, Братислава, прямо в аэропорт Катовице): цена, время в пути и ссылка
  отдельной строкой; ★ остаётся у перелёта.
- **Дозор и интерес** — «следи за ценой на февраль», «в ноябре интересна Испания до 1500 zł»: cron, свод по
  понедельникам, флэш-распродажи — в день сбора.
- **Рассылки перевозчиков** (если у агента есть Gmail) — письма авиакомпаний уходят под ярлык мимо Входящих, акции
  с ценами — и однодневные «до полуночи» без даты (LOT «Szalona Środa») — попадают в таблицу «Распродажи», в поиск и
  в утренний свод «⚡» (если письмо пришло до него).
- **Ссылка у каждого плеча** — плагин `travel-links` сверяет готовый ответ с отчётом и дописывает ссылки на покупку,
  которые модель пропустила (у авиакомпании, если она есть в журнале).
- **★ — у самого дешёвого** — тот же плагин снимает ★ с варианта дороже ★ скрипта (модель ставила её «тёплому») и
  ставит строкой самого дешёвого до двери с плечами и ссылками; тёплый остаётся вариантом словами.
- **Честность цен** — каждая цена хранится строкой журнала с адресом продавца и фрагментом выдачи; реклама «от 99 zł»
  и кэш в вариант не попадают.

## Установка

Одно сообщение своему агенту:

> установи travel-скилл из https://github.com/ilya0013/hermes-travel-skill — инструкция в `INSTALL.md`

Агент клонирует репозиторий, запустит `install.sh`, задаст три вопроса (Модлин годится? сколько человек? есть ли
интерес на ближайшие месяцы?) и заполнит профиль. Человек в терминал не ходит. В конце агент попросит отправить ему
`/restart`, затем `/new`: без этого роль в мессенджере не появится. Что именно делает `install.sh` — в его шапке;
повторный запуск безопасен.

**Обновление** — то же сообщение агенту: файлы роли перезапишутся, `profile.yaml` и журнал останутся. Какая версия
стоит — `version:` в `skills/travel/travel-role/SKILL.md`; какие вышли —
[теги репозитория](https://github.com/ilya0013/hermes-travel-skill/tags) (тег `vX.Y.Z` = `version: X.Y.Z` роли).

**Требования:** Hermes Agent в Docker (Linux), Python 3.13 и `uv` в контейнере (есть в образе). По желанию: Google
(Диск, Таблицы, Gmail) через `hermes auth`, бесплатный аккаунт SlickTrip.

## Как это работает

```
просьба человека
  → опрос: до пяти вопросов (даты и допуск, сколько человек, багаж, Модлин или Шопен, цена или удобство)
  → сбор: скрипты-источники пишут каждую цену строкой в журнал travel/observations.jsonl
  → report.py --auto: поездки из строк, сумма до двери, ★, таблица на Диск
  → slicktrip.py book: ссылка на оплату у авиакомпании (если подключён SlickTrip)
  → ответ человеку: вердикт, 2–3 варианта, риски, источники ✅/❌
  → плагин travel-links: ссылка на покупку у каждого плеча, которую агент пропустил, — дописывается из журнала;
    ★ не у самого дешёвого по report.py — переставляется
```

**Порядок доверия к цене:** перевозчик (Ryanair) → Google Flights (упал — Skiplagged) → Kiwi → страница продавца
своими глазами.

**Статусы цены:** ORIENTIR (реклама, кэш, карта минимумов) → QUOTED (выдача на даты) → CONFIRMED (страница тарифа
продавца). В вариант идут только QUOTED и CONFIRMED.

Подробности — `skills/travel/travel-role/SKILL.md` (шаги агента), `references/sources.md` (что умеет каждый
источник и чем заменить упавший), `references/journal-contract.md` (формат строки журнала), `references/watch.md`
(дозор, интерес, рассылки).

## Что внутри

```
install.sh                         установка: роль, venv (uv), каталоги, cron-обёртки
INSTALL.md                         шаги для агента: команда, вопросы, профиль, проверка
requirements.txt                   mcp, fast-flights, flywizz, ryanair-py, requests
skills/travel/travel-role/
  SKILL.md                         роль: когда включаться и шаги работы
  profile.yaml                     дом, аэропорты, дорога, пассажиры
  references/                      источники, контракт журнала, дозор и интерес
  scripts/                         источники цен, report.py, slicktrip.py, журнал
  plugin/                          плагин Hermes travel-links (install.sh кладёт в plugins/ и включает)
scripts/travel/interest_digest.sh  обёртка cron для свода по интересам
scripts/travel/mail_sales.sh       обёртка cron для писем перевозчиков (нужен Gmail)
```

Профиль по умолчанию — Варшава: Шопен (ZTM 4,40 zł), Модлин (автобус, ориентир 35 zł, живая цена — Flixbus),
1 взрослый, папка «Поездки» на Диске. Другой город — агент впишет аэропорт и цену дороги по образцу.

## Ограничения

- Цены — на момент запроса; покупка и проверка тарифа на сайте продавца — за человеком.
- Сайты Wizz Air и Kiwi закрыты бот-гейтом: цену Wizz роль берёт из Google Flights, ссылку на покупку даёт на
  wizzair.com.
- Google Flights без браузера хрупок: упал — роль скажет об этом в ❌, а не «рейсов нет». Багажа в строке Google нет —
  при чемодане цену с багажом даёт Kiwi.
- Ссылка у авиакомпании — только с аккаунтом SlickTrip и только для рейсов, которые авиакомпания продаёт сама.
- Skiplagged ограничивает частоту (~11 запросов, дальше блок на минуту): скрипт идёт раз в 10 с, «куда угодно» на месяц
  выходных — 1–3 минуты. Цены у него в долларах, багажа в строке нет.
